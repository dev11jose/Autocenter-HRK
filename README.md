> [!WARNING]
> **Aviso de Projeto Academico**
> Este repositório contém um projeto de cunho estrimamente educacional.trata-se de um **protótipo Front-end** e **não é 100% Funcional**. A aplicação não possui integração com um banco de dados real (Back-End) ou gateways de pagamento (Checkout real).

 ##  O que o projeto apresenta no momento?

Apesar de ser um protótipo, a aplicação demonstra conceitos sólidos de desenvolvilmento web, onde a oficina possa ver os carros que estão lá, quais serviços estão sendo feitos e quais orçamentos ainda precisam ser aprovados.

<details>
<summary>🎨<b> Veículos</b></summary>
<br>
mostra os carros cadastrados, os clientes, as placas e os serviços. Também dá para pesquisar e mudar o status do atendimento para fazer uma demonstração.
</details>

<details>
  <summary>📏 <b>Orçamentos</b></summary>
  <br>
  mostra os valores dos serviços e permite clicar para simular a aprovação.
</details>
